# 自托管测试版验收 — 2026-09-05

历史状态（2026-09-05）：当时为本地候选发行版。以下结果对应当时的实现与运行；当前源码入口见根 README。原 P0 全链路与外部 Agent 记录链路分别验证；外部记录没有自动进入受保护保险赔付。

## 已实现

- 中文工作台按运行记录、接入 Agent、测试工作流、使用帮助分层；即时下载为运行详情主操作，验证与原始记录按需展开；补证、部分批准进入审核表单。
- Node TypeScript SDK 包装已有支付函数，持久化请求后执行；operationId 重复拒绝、未知结果要求对账、单写者 spool、重启校验、显式字段映射、常见凭证键过滤、断网补传。
- Agent 接入凭证只可采集自身记录；服务端接受有序摘要事件，拒绝改写和缺口，同批重传不重复；凭证可撤销，哈希在加密数据库中保存。
- afr-snapshot/1 单独格式；未授权草稿、运行中、未分析、未审核都可导出。最终包仍严格要求决定文件，不能删除决定来伪装快照。快照当前不上链，整体 incomplete；它证明已披露材料的签名与完整性，不等于完整案件、来源事实或保险结论。
- 原 P0 的授权存证、支付、AI 分析、审核、测试赔付、最终包上链和独立核验保留。

## 发布范围和未过门

可以在本机试用 SDK 和控制台，或用 CLI 独立验证。发行包不含密钥；服务绑定 loopback。客户端 spool 为 0600 文件、并非应用层加密；只用于合成数据/测试网试用。每次运行上限 2000 个事件或 8 MiB，单事件 128 KB；超限停止新的受包装付款，已有记录保留。

硬件 TEE、真实客户隐私/租户隔离、真实保单条款与保险方认可、其他支付轨道、公网托管未完成。MetaMask 真人签名/审核演示、S4 五轮、T+72h 和对外发布仍按原验收门处理。本轮未宣称成为保险生产服务。

已完成代码级集成不等于所有外部支付平台已适配：当前提供通用函数包装与一个 viem 测试网示例；其他渠道必须自行映射字段并扩展独立回执核验。
