# 现场运行手册

目标：5–8 分钟内展示一个真实案件从授权到独立核验的全过程。仅 chain 1439、AFR-TEST-USD；全部事件均有真实 tx/文件证据。

## 准备

1. 启动服务，检查 Gateway/verifier/operator/fixture 健康，确认测试钱包余额与 Vault 测试资产余额。
2. 在准备演示的浏览器中登录工作台并连接 MetaMask 测试账户。签署清晰的任务、限额、有效期与网络域。不要展示私钥或密码。
3. 角色：操作者授权和运行 Agent；审核员读证据、输入决定；评委下载完整包并独立验证。可一人切换角色，但须口头说明。
4. 可预置已确认的攻击付款以降低模型不服从攻击、延迟和网络风险。必须展示真实运行时间、lineage 和 tx，不冒充当场购买；新决定与赔付须重新产生最终包。

## 现场顺序

- 0:00–0:45：问题：事后仅有转账记录，无法说明授权、Agent 读到的输入和损失处理。说明受控攻击与测试资产边界。
- 0:45–2:00：展示签名授权与 AUTH 上链、工具调用、付款与交付。若 Agent 拒绝攻击，展示无损失关闭结果，转至明确标注的历史攻击付款案例。
- 2:00–3:30：实时调用 AI，展示原文引用和硬规则。模型输出只是建议，不能自动赔付；校验失败显示补证/不可用。
- 3:30–4:30：审核员解释决定并批准测试赔付，展示 Vault 实际交易回执；不得把自动化 QA 点击称为真人决定。
- 4:30–6:00：生成新最终包并存证，下载 ZIP；另一终端使用独立 CLI 读取真实 RPC。停止平台仍能验证下载包。
- 6:00–7:00：修改证据的负例应 Fail；public 包 withheld 原文应 incomplete；解释信任配置与软件级声明的上限。

## 故障处理

| 情况 | 操作 | 不得声称 |
|---|---|---|
| 模型拒绝攻击 | 显示实际拒绝与无付款结果；切换已披露的历史攻击付款案例 | 不能改造结果冒充攻击成功 |
| AI 输出无效/供应商不可用 | 显示 Not Available / Needs Information，真实重试；可演示既有有效分析但标时间 | 不能把缓存说成新调用 |
| RPC 不可达 | 保留 Pending/Unknown；用 --offline 展示局部完整性，恢复网络后重查 | 不能把历史绿灯当当前网络结果 |
| 钱包扩展缺失/拒签 | 停在授权前；可展示明确标注的软件测试签名案例 | 不能说 MetaMask UI 已实测 |
| 付款/赔付等待中断 | Reconcile/Retry 查询或重发同一已签名交易；不得生成新意图来补付 | 不能仅凭提交 hash 标 Paid |

## 视频

最终提交视频建议 3 分钟，需真人演示审批节点。保留完整连续原始录制，允许的时间压缩必须屏显并在 VIDEO-LOG.md 记载。当前 ego 自动化录像用于 QA；只有真人操作确认并核对赛事规则后，才能把最终视频标为提交就绪。
